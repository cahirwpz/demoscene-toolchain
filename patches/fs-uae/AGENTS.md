# patches/fs-uae/

Patches for the fs-uae emulator build (submodules/fs-uae, WinUAE fork with the
fsemu frontend). Each carries a prose header. Platform layer: src/od-fs/,
src/fsuae/, fsemu/, libfsemu/.

fs-uae is a live debugger backend for `uaedbg`; it meets the same console +
uaelib contract documented in ../amiberry/AGENTS.md.
